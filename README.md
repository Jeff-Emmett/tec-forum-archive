# TEC Forum Archive

A read-only reconstruction of `forum.tecommons.org`, the Token Engineering Commons Discourse forum.
The forum went offline with the TEC DAO's shutdown, and no export was published. This archive is
rebuilt from public web-archive captures (Internet Archive Wayback Machine and Common Crawl).

**Live:** https://tec.mycostack.xyz

**Source:** https://gitea.jeffemmett.com/jeffemmett/tec-forum-archive (primary), mirrored to
https://github.com/Jeff-Emmett/tec-forum-archive

Old forum links work once the host is swapped: `forum.tecommons.org/t/<slug>/<id>` →
`tec.mycostack.xyz/t/<slug>/<id>/`.

## Pipeline

```
scraper/enumerate.py  data/sources          # list every capture (Wayback CDX + each Common Crawl index since 2020)
scraper/fetch.py      data/sources raw      # download captures, content-addressed, resumable (raw/manifest.jsonl)
scraper/parse.py      raw data              # merge posts across captures -> data/topics/<id>.json, data/index.json
scraper/build.py      data raw site         # static site
npx pagefind --site site                    # full-text search index
```

Set up once: `uv venv .venv && uv pip install --python .venv/bin/python -r requirements.txt`, then
run each stage as `.venv/bin/python -I scraper/<stage>.py …`. `fetch.py` takes an optional shard
(`0/3`, `1/3`, `2/3`) so several processes can share the download. Downloaded captures are untrusted input: they are only ever passed as paths.

### Merge rules

- Every capture of a topic is a bag of posts. Posts are unioned by `post_number`; when several
  captures hold the same post the newest capture wins (latest edit).
- Newer captures embed Discourse's preloaded topic JSON (display names, reply targets, likes,
  category table). Older ones only have the crawler view (body, author, dates). Both are parsed.
- Moderator small-actions (pin, close, move) are kept as actions, so they are not mistaken for
  lost posts.
- Every post records the capture it came from (`source`), and every topic lists all captures used.
- Topics named in sitemaps, topic lists or suggested-topic blocks but never captured are kept in
  `data/index.json` with `archived_posts: 0` and listed on `/missing/`.

### Sanitising

Archived HTML is third-party content. `build.py` strips scripts, styles, forms, embeds, event
handlers and `javascript:`/`data:` URLs, rewrites forum links into the archive (or to the Wayback
Machine when the target was not captured), and serves under a strict CSP (`nginx.conf`).

## Layout

| path | what |
|---|---|
| `raw/` | every downloaded capture, gzipped, named by sha256, plus `manifest.jsonl` (source, timestamp, URL, status) — the evidence |
| `data/sources/` | the capture indexes as fetched |
| `data/` | merged records (regenerated by `parse.py`; the Docker build reruns it) |
| `site_src/` | templates and CSS |

## Deploy

`docker compose up -d --build` on Netcup (`/opt/websites/tec-forum-archive`). The image build
reruns parse + build + pagefind from `raw/`, so the repo alone reproduces the site.
Traefik router `tec-forum-archive`, host `tec.mycostack.xyz`, Cloudflare tunnel ingress via
`dev-ops/cloudflare/cf-onboard.py`. The origin answers this host only via the tunnel or tailnet
(`dev-ops/security/origin-lock`; regenerate it whenever a hostname is added).

## Filling gaps

A Discourse admin backup (`/admin/backups`, `.tar.gz`) from a former forum admin would complete
the archive. Before publishing anything from one: strip emails, IPs, private messages and
non-public categories.
