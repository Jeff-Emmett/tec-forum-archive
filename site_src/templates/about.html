About this archive

The Token Engineering Commons ran a Discourse forum at forum.tecommons.org from {{ site.first|year }}. The TEC used it for funding proposals, hatch and commons-configuration debates, working-group reports, Praise and rewards analysis, and the governance decisions that ended in the claims process. The forum went offline when the DAO shut down, and no export was published.

This site rebuilds it from public web archives. It is read-only and unofficial. It sits alongside other commons-tooling histories preserved by the MycoStack project.

What was recovered

  • {{ site.topics }} topics with at least one post, out of {{ site.known }} public topics named in the forum's own sitemaps and topic lists.
  • {{ site.posts }} posts by {{ site.people }} people, dated {{ site.first|date }} to {{ site.last|date }}.
  • {{ site.complete }} topics are verified complete against a post count the forum itself published. Topics known to be missing replies say where the gaps fall. For the rest no count survives, so completeness can't be checked.
  • {{ site.spam }} spam topics (cracked-software link drops from after moderation stopped) are left out. They are listed in excluded-spam.json.
  • Built from {{ site.wayback_captures }} Internet Archive Wayback Machine captures and {{ site.cc_captures }} Common Crawl captures.

How it was made

  1. Every capture of the forum was listed from the Wayback Machine's CDX index and from each Common Crawl index since 2020.
  2. Each distinct capture of a topic page was downloaded unmodified. Newer captures include Discourse's preloaded topic JSON, which carries display names, reply links and likes. Older ones carry the crawler view, which has the post body, author and dates.
  3. Posts were merged by their number within each topic. Where several captures held the same post, the newest one was kept, since it carries the latest edit. Every post links back to the capture it came from.
  4. Post HTML was sanitised. Links between topics were rewritten to point inside this archive, and everything else points to the Wayback Machine. Images were kept wherever a crawler had saved them.

The same posts are also loaded into a read-only Discourse at tec.mycostack.xyz, so the forum can be read the way it looked, with Discourse's own search, user pages and threading. It keeps the forum's topic and post numbers: forum.tecommons.org/t/<slug>/<id> becomes tec.mycostack.xyz/t/<slug>/<id>. This site, tec-archive.mycostack.xyz, is the evidence view: which capture every post came from, and where the gaps are. The same paths work here.

Data

The merged corpus, one topic per line with every post and its source capture: tec-forum-archive.jsonl.gz. The index of all known topics, captured or not: index.json. Scraper and site source: gitea.jeffemmett.com/jeffemmett/tec-forum-archive.

Filling the gaps

The archive could be completed from a Discourse admin backup (the .tar.gz under /admin/backups). If you ran the forum and still hold one, or kept saved pages or exports of particular threads, please open an issue on the repository above. A backup would be stripped of emails, IP addresses and private messages before anything from it is published.

Corrections and removal

Everything here was publicly posted and publicly archived. If you wrote a post and want it removed or attributed differently, open an issue on the repository and it will be handled.
